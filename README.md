# Laurent Bouriez

Page personnelle statique. Le volet Pro s’ouvre par défaut. Le fragment `#personnel` ouvre directement le volet Personnel. Le site fonctionne avec HTML, CSS et JavaScript, sans installation de dépendances.

## Développement local

Depuis ce dossier, lancer `py -m http.server 8765 --bind 127.0.0.1`, puis ouvrir `http://127.0.0.1:8765/`.

## Contenu et publication

Les liens et textes sont dans `index.html`. GitHub Pages sert les fichiers à la racine de la branche `main`. Le lien direct vers le volet Personnel est `https://lbouriez.github.io/#personnel`.

Le calendrier de la chouette est dans `seasonal-owl.js`. Les illustrations et animations sont dans `assets/logo/seasonal`. Le lecteur Lottie est chargé au premier clic sur la chouette ou le pseudonyme.
